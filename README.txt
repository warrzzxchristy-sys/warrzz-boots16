WARRZZ BOOST — TikTok Public Account Checker

CARA DEPLOY KE VERCEL
1. Ekstrak ZIP ini.
2. Buat repository GitHub baru, lalu upload semua isi folder (index.html, api/profile.js, vercel.json, package.json).
3. Buka Vercel dan pilih Add New -> Project.
4. Import repository GitHub tadi, lalu Deploy.
5. Buka alamat .vercel.app yang diberikan Vercel.

CARA PAKAI
- Buka website.
- Masukkan username TikTok tanpa password, misalnya @username.
- Tekan "Cek akun otomatis".

BATASAN
- Endpoint mencoba membaca data yang tersedia pada halaman profil publik TikTok.
- TikTok dapat mengubah struktur halaman atau membatasi permintaan otomatis; karena itu hasil tidak dijamin selalu tersedia.
- Tidak bisa mengambil data akun privat, insight kreator, demografi penonton, atau data internal.
- Jangan pernah menambahkan password, OTP, atau cookie akun.
- Proyek ini tidak berafiliasi dengan TikTok.

Jika TikTok menolak permintaan, halaman akan menampilkan pesan dan pengguna dapat membuka profil TikTok secara langsung.
